# @ylfjuk-core/types &middot; ![GitHub License](https://img.shields.io/github/license/ylfjuk/core) ![NPM Version](https://img.shields.io/npm/v/%40ylfjuk-core/types?logo=typescript)

TypeScript utility types used by [`@ylfjuk/core`](../core/README.md).

## Install

```sh
pnpm add @ylfjuk-core/types
```

The package is type-only, uses ESM package metadata, and requires TypeScript 7.

```ts
import type { Result } from "@ylfjuk-core/types";
```

## Development

From the repository root, use Node.js 22.18.0 or newer and run `pnpm run test` and `pnpm run test:types`.
